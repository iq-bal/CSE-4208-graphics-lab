% ------------------------- SECTION 1: INTRODUCTION -------------------------
\section{Introduction}

\subsection{Project Overview}
``The Crypt of Thoth" is an immersive interactive 3D Ancient Egyptian Tomb exploration simulation built using the modern OpenGL rendering pipeline. The virtual environment represents an architecturally authentic ``T-shaped" burial chamber featuring an exterior desert biome, intricate descending corridors, pillared traverse halls, and a fully interactive burial chamber complete with a sliding sarcophagus mechanism. The project is meticulously programmed without rely on pre-compiled 3D modeling frameworks, utilizing hierarchical procedural geometry constructed entirely in C++ code. The visual fidelity encompasses algorithmic procedural geometry, dynamic texture blending, complex light attenuation, and immersive camera controls.

\subsection{Objectives}
The primary objective of this project is to create an engaging visual experience showcasing foundational and advanced computer graphics techniques. Key goals include:
\begin{itemize}
    \item Implementing a real-time rendering pipeline with core OpenGL, GLAD, and GLFW.
    \item Procedural geometry computation demonstrating hierarchical matrix stacking.
    \item Dynamic rendering elements such as Bezier curve displacement and fractal generation.
    \item Complex mathematical lighting paradigms incorporating Point, Spot, and Directional sources with accurate attenuation parameters.
    \item Emulating realistic surface qualities leveraging multiple texture maps and Phong reflection per-fragment shading.
\end{itemize}

% ------------------------- SECTION 2: THEORETICAL FOUNDATION -------------------------
\section{Theoretical Background}

\subsection{Geometry \& Mathematical Modeling}
\textbf{Bezier Curves:} A parametric curve used extensively in computer graphics. Displacing points based on control polygon constraints, cubic equations of degree 3 interpolate between start and endpoints while being stretched towards inner control points. This principle is utilized to perturb the rigid geometry of the exterior ocean surface, creating dynamic wave meshes. 
\\
\textbf{Fractals:} A geometric figure exhibiting self-similarity evaluated via recursive functions. In our simulation, the lush crowns of the desert palm trees are algorithmically constructed using fractal generation, dynamically spawning variable geometrical branches based on recursive depth configurations to synthesize dense, organic foliage.

\subsection{Shading & Illumination (The Phong Model)}
The illumination simulates how light reacts physically when hitting object surfaces, calculated natively using the local \textit{Phong Reflection Model}.
The fundamental formulation defines light via:
\begin{enumerate}
    \item \textbf{Ambient Lighting ($I_a$):} Global illumination minimum bounds ensuring objects shadowed by direct beams retain minimal visibility ($I_a = k_a L_a$).
    \item \textbf{Diffuse Reflection ($I_d$):} The matte reflection defining how light scatters directionally depending on the incidence angle (dot product) relative to the vertex normal vectors ($I_d = k_d L_d \max(N \cdot L, 0)$).
    \item \textbf{Specular Highlights ($I_s$):} Simulated glossiness calculated from the reflection vector matched against the camera's angle of observation, raised to a shininess exponent evaluating highlight tightness ($I_s = k_s L_s \max(R \cdot V, 0)^{\text{shininess}}$).
\end{enumerate}

\subsection{Texturing \& Blending}
Surface fidelity is augmented via bounding 2D imagery (texture maps) across triangle vertex attributes. The inherent interpolation processes within the rasterization pipeline algorithmically map UV coordinates. Furthermore, sophisticated \textit{Fragment Blending} interpolates output values via linear interpolations ($\text{mix}(x, y, a)$), enabling multi-texture overlay masks for realistic sand, water intersections, and volumetric sky-fog.

\subsection{Viewing \& Projection Matrices}
Translating the 3D local coordinate scenes onto a 2D monitor screen relies on consecutive transformation matrices:
\begin{itemize}
    \item \textbf{Model Matrix:} Maps local space to World Space (translations, rotations, scaling).
    \item \textbf{View Matrix:} Translates the world relative to the dynamic camera lens (\texttt{glm::lookAt}).
    \item \textbf{Projection Matrix:} Simulates perspective and distortion (\texttt{glm::perspective} for dynamic FoV representation or \texttt{glm::ortho} for Flat/Top/Isometric bounding boxes).
\end{itemize}


% ------------------------- SECTION 3: TECHNICAL IMPLEMENTATION -------------------------
\section{Technical Implementation}

The architecture heavily relies on vertex and fragment shaders (\texttt{vshader.glsl} and \texttt{fshader.glsl}). Real-time manipulations traverse via uniform variables allowing decoupled code logic to manipulate visual states.

\subsection{Geometry Construction \& Matrix Stacks}
Complex structures such as the \textit{Pendulum Traps} and \textit{Pillared Corridors} invoke Hierarchical Modeling. The blade trap is evaluated computationally:
$$ M_{\text{world}} = M_{\text{ceiling}} \cdot M_{\text{rotation}}(t) \cdot M_{\text{arm}} \cdot M_{\text{blade}} $$
Where $M_{\text{rotation}}$ oscillates via the sinusoidal representation $\theta(t) = \theta_{\text{max}}\sin(2\pi ft)$.

\subsection{Multi-Source Lighting Environment}
The interior and exterior are populated by distinct lighting properties simultaneously evaluated by \texttt{fshader.glsl}:
\begin{itemize}
    \item \textbf{Directional Light:} Evaluated indefinitely mimicking the sun tracking the Egyptian Desert.
    \item \textbf{Point Lights:} Bound natively to the interior lantern mechanisms. Falloff distances are bound quadratically using the inverse square law parameter approximations: $I = I_0 / (K_c + K_ld + K_qd^2)$. We further appended fractional procedural Gaussian noise parameters instantiating flickering fire illusions.
    \item \textbf{Spotlights:} Implemented as an explicit flashlight mechanics, restricting angle bounds to an arccosine cutoff ($\sim 14^\circ$ tight beams) tracking the dynamic camera vectors natively.
\end{itemize}

\subsection{Interactive Component Behaviors}
User dynamics map to immediate transformations evaluated every frame delta ($dt$). Triggering the sarcophagus interpolates a linear transformation ($T(0, y_{\text{offset}} + y_{\text{slide}}, 0)$) revealing the interior visually whilst updating interaction radii dynamically.

\section{Interaction Design \& User Controls}
To deeply interact with the computer graphics properties demonstrated within the codebase, multiple runtime toggles alter the shader uniformity directly. 

\subsection{Base Navigation}
\begin{itemize}
    \item \textbf{W/A/S/D:} Positional Movement.
    \item \textbf{Mouse Drag:} Pitch and Yaw mapping updating \texttt{glm::lookAt} vectors.
    \item \textbf{Space / Shift:} Vertical translation for debugging aerial environments.
\end{itemize}

\subsection{Graphics Manipulations}
Interactive mechanisms toggle rendering equations mathematically bridging algorithm inputs with tangible visual outputs:
\begin{table}[H]
\centering
\begin{tabular}{@{}llp{8cm}@{}}
\toprule
\textbf{Shortcut} & \textbf{Concept} & \textbf{Functionality / Result} \\ \midrule
\texttt{[ / ]} & Bezier Curve & Adjusts cubic wave amplitudes decreasing/increasing displacements.\\
\texttt{, / .} & Fractals & Alters recursive depth variables iterating palm foliage elements.\\
\texttt{T} & Texture Map & Toggles sampling binding, reverting shapes back to default raw primitives.\\

\texttt{8 / 9} & Shininess & Alters bounding parameters tightening/widening focal highlight gradients.\\
\texttt{1, 2, 3} & Lighting & Toggles Directional Sunlight, Interior Point Lanterns, or Handheld Spotlights.\\
\texttt{0} & Spotlight Cone & Iterates angular beam radiuses evaluating fragment visibility arcs.\\

% ------------------------- SECTION 6: CONCLUSION -------------------------
\section{Conclusion \& Future Work}
The \textit{Crypt of Thoth} encapsulates an effective translation of the mathematical theorems bounding modern real-time computer graphics strictly toward an interactive virtual simulation. It perfectly executes fundamental mechanics incorporating procedural geometries ranging from Bezier displacement maps to recursive branching models without leaning on third-party design models. The project succeeds in rendering highly atmospheric fidelity mimicking per-pixel illumination matrices mapped dynamically to user location context mapping.

\textbf{Future Prospects:} 
In iterations beyond this foundational framework, there are immense possibilities to increase graphical complexities linearly. Advancements integrating shadow volume mapping algorithms would natively simulate obstruction, appending significant visual realism inside the narrow pillared corridors. Additional particle emission setups mapping physical dust vectors or lantern smoke using transform feedbacks bounds another layer of sensory enhancement to the ancient environments.
